Auckland Full-Population Model

Base-year weekday travel for everyone in the Auckland synthetic population, from the road-assignment stability run behind the congestion-pricing work. Far more journeys now finish and road counts fit better, but the model is still not validated.

!
Warning: not a calibrated forecast. These are published outputs, and the combined acceptance check did not pass. See what passed and what did not.
Run completion

Far fewer journeys were left unfinished

This run stabilised car route assignment only. Every trip origin, destination, mode and main activity time was kept, and no people or trips were removed. The earlier run is the better-completion run; the previous run is the latest cycling run.
